# پروژه‌ی درس آمار و کاربردها — پاییز ۱۴۰۵

**مسیر:** الف — NHANES 2021–2023
**دانشجو:** آیدا عباسی — شماره دانشجویی: ۴۰۱۱۷۰۸۹۷
**وضعیت فعلی:** فاز ۱ تکمیل‌شده (برچسب `phase-1`)

سؤال آماری اصلی پروژه و جزئیات کامل در [`PROJECT_CARD.md`](PROJECT_CARD.md)
آمده است. خلاصه: بررسی ارتباط میانگین فشارخون سیستولیک بزرگسالان آمریکا با
مدت خواب، بی‌تحرکی، وضعیت دخانیات و BMI (با کنترل سن/جنسیت)، با استفاده از
داده‌ی عمومی NHANES.

## ساختار مخزن

```

  build_notebook.py       نوت‌بوک را از نو می‌سازد
  build_report.py         reports/phase1.pdf را از نو می‌سازد

  phase2/ phase3/ phase4/ final/   برای فازهای بعدی

```

## بازتولید کامل تحلیل

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# ۱. دانلود داده‌ی خام (نگاه کنید به data/README.md برای جزئیات/لینک‌ها)
mkdir -p data/raw
BASE="https://wwwn.cdc.gov/Nchs/Data/Nhanes/Public/2021/DataFiles"
for f in DEMO_L BPXO_L BMX_L SLQ_L PAQ_L SMQ_L; do
  curl -sS -o "data/raw/${f}.xpt" "${BASE}/${f}.xpt"
done

# ۲. ساخت و اجرای نوت‌بوک
python3 src/build_notebook.py
jupyter nbconvert --to notebook --execute --inplace notebooks/phase1_exploration.ipynb

# ۳. ساخت گزارش PDF نهایی
python3 src/build_report.py
```

## یادداشت درباره‌ی اصالت کار

طبق دستورالعمل درس، کد آغازین تهیه‌شده توسط دستیاری مجاز است، اما هر
دانشجو باید بتواند **هر بخش از کد و تحلیل خود را در جلسه‌ی دفاع شفاهی
توضیح دهد** — نمره‌ی نهایی حاصل‌ضرب امتیاز خام در یک «ضریب تسلط» ۰ تا ۱ است
که در همان جلسه تعیین می‌شود. پیش از جلسه‌ی دفاع حتماً منطق هر بخش
(`src/analysis.py`، معیارهای ورود/خروج در PROJECT_CARD، و تفسیر هر جدول و
نمودار در `reports/phase1.pdf`) را مرور و برای توضیح آماده شوید.
